# Claim scope and limitations

The result concerns arbitrary deterministic policies using unrestricted real linear queries with exact answers. The winner at a terminal history must be optimal for every cost consistent with that history. The minimum is worst-case query count. Preprocessing time, evaluation time and bit complexity are outside the bound.

The original scope has a bounded rational feasible polytope and a nonempty convex ambient-open rational H-polyhedral cost prior. The unbounded and bounded polyhedral examples both fit this scope. The ellipsoid and its rational quadratic membership test give an extension beyond the polyhedral question.

The finite replay tests the example policies and the worked figure. It does not implement general real quantifier elimination. Approximate answers, measurement noise, restricted query libraries and randomization remain outside this note. External peer review and formalization are pending.
